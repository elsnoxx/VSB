Advanced VPN Configuration Using Wireguard

Úvod

Cílem projektu je vytvorit tesbed prostredi kde se vyskouzsi jedny z nejznamejsich scenaru pro spojeni pomoci VPNa to presneji pro 1:1, N : 1 a komunikace za pomoci PKI, implementace scénářů 1:1 (klient–server) a N:1 (hub-and-spoke: více klientů přes centrální server), metodické otestování (konektivita, propustnost) a jednoduché napojení na „PKI-light“ kde se udela evidence a ukazku revokace pristupu. tento web je dokumentace prave toho vytvareni s screenshoty a popsanymi kroky.

Wireguard

Wireguard je moderní VPN protokol, který je známý svou jednoduchostí, vysokou bezpečností a efektivitou. V tomto projektu bude použit pro konfiguraci různých VPN scénářů. Konfigurace je staickaa jednoduse citelna sluzba bezi v systemd jako servise vzdy jako wg-quick@interface

Typicke Konfigurace

  • 1 : 1 - road-warrior
  • N : 1 - hub-and-spoke
  • Pripadne site to site

Pro konfiguraci Wireguard VPN je potřeba vygenerovat klíče pro server i klienty a následně vytvořit konfigurační soubory s těmito klíči a příslušnými nastaveními.

Implementace (testbed, 1:1 a N:1)

Testbed jsme vytvoril za pomoci 3 linux debian VM serveru. Kde jsou pojmenovane podle funkce: WireguardServer, WireguardClient1 a WireguardClient2. kazda vm ma dva adaptery jeden jako NAt a jedne pro hostonly. VPN sit je natavena s prefixem 10.13.1.0/24 a to na rozhrani wg0. Naserveru je povolen ip forwarding a taky jednoduche pravidlo v ip tables pro povoleni komunikace mezi klienty a centralnim prvkem.

Postuo

Vytvoření testbed prostředí

Pro vytvoření testbed prostředí byly použity tři Debian VM: WireguardServer, WireguardClient1 a WireguardClient2. Každá VM má dva síťové adaptéry: jeden pro NAT a druhý pro host-only síť. VPN síť je nastavena s prefixem 10.13.1.0/24 na rozhraní wg0.

Na serveru je povolen IP forwarding a nastavena jednoduchá pravidla v iptables pro povolení komunikace mezi klienty a centrálním serverem.

Konfigurace Wireguard

Po vytvoření testbed prostředí a ověření síťové konektivity je dalším krokem konfigurace Wireguard VPN. To zahrnuje vygenerování klíčů pro server a klienty a vytvoření konfiguračních souborů s těmito klíči a příslušnými nastaveními.

Ping test

Pro ověření konektivity mezi serverem a klienty se provádí ping testy. To zahrnuje odesílání ICMP echo requestů z klientů na server a naopak, aby se potvrdilo, že VPN tunel je funkční.

Zobrazeni tunelu a handshaku

pro overeni stavu tunelu a potvrzeni handshaku se pouziva prikaz wg show na serveru i klientech. Takze si ukazeme jak vypada revokace po odebrani peera neboli klienta 2 ze serveru, ktery se jiz nebude zobrazovat

Ověření konektivity VPN

Po konfiguraci Wireguard VPN je důležité ověřit, že VPN tunel funguje správně. To zahrnuje kontrolu IP adres přiřazených rozhraním wg0 na serveru i klientech a testování konektivity mezi klienty a serverem.
